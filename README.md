# 👔 FORME — Modern Menswear E-Commerce Platform

A full-stack, responsive e-commerce web application designed for curated menswear fashion. Built with a robust **Node.js & Express** backend, a **MongoDB** database, and a clean, minimalist front-end user experience.

---

## ✨ Features

### 🛍️ User Storefront
* **Product Catalog:** Browse curated collections (Outerwear, Tailoring, Knitwear, Accessories) with category filtering and keyword search.
* **Dynamic Product Details:** View high-resolution image galleries, sizing charts, material descriptions, and real-time inventory status.
* **Interactive Cart & Drawer:** Slide-out shopping bag featuring live subtotal calculations and dynamic item updates without page reloads.
* **Responsive UI:** Fully optimized across mobile, tablet, and desktop viewports with modern typography and sleek minimalist design.

### ⚙️ Admin Dashboard
* **Analytics Overview:** Monitor real-time store performance, revenue metrics, and inventory health.
* **Inventory & Product Management:** Complete CRUD functionality to add, edit, feature, or remove products and update stock levels.
* **Order Tracking:** View active customer orders, update delivery statuses, and review transactional histories.

---

## 🛠️ Tech Stack

* **Backend:** Node.js, Express.js
* **Database:** MongoDB (Mongoose ODM)
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Authentication & Security:** JSON Web Tokens (JWT) / Express Sessions, bcrypt password hashing
